\# FUTURE\_CS\_02 – Phishing Email Detection \& Awareness System



\## Task Overview

This repository documents a Phishing Email Detection \& Awareness exercise conducted as part of the Future Interns Cyber Security internship (Task 2).



\## Tools Used

\- Phishing email samples (public datasets / collected samples)

\- Email header analyzer

\- Browser tools

\- Google Docs / MS Word / PDF (for report)



\## Objective

\- Identify phishing indicators (spoofed sender, fake domains, malicious links)

\- Classify emails as Safe / Suspicious / Phishing

\- Explain phishing techniques in simple, business-friendly language

\- Provide clear prevention and awareness guidelines for users



\## Deliverable

A professional Phishing Detection \& Awareness Report including phishing examples, risk explanation, and prevention guidelines (see `/reports` folder).
